# Warehouse Interactive Learning

เว็บบทเรียน **บทที่ 1 พื้นฐานการจัดการคลังสินค้า** สำหรับใช้สอนและทำกิจกรรมระหว่างเรียน

## ฟังก์ชันหลัก
- แสดงเอกสาร/สไลด์ PDF
- กิจกรรมระหว่างเรียนและแบบฝึกหัดท้ายบท
- ช่องคำตอบบล็อก Paste / Drop / Ctrl+V / Cmd+V
- พิมพ์หรือ Save as PDF เพื่อส่งอาจารย์
- Teacher Mode เพิ่ม/แก้ไขเนื้อหาและกิจกรรมได้
- Export / Import เนื้อหาเพิ่มเติมเป็น JSON
- บันทึกคำตอบใน browser ด้วย localStorage

## ไฟล์สไลด์
หน้าเว็บจะพยายามโหลดไฟล์ `warehouse_ch1.pdf` จาก root ของ repository อัตโนมัติ  
หากยังไม่มีไฟล์ดังกล่าว สามารถกด **เปิด PDF จากเครื่อง** ในหน้าเว็บได้

## GitHub Pages
ตั้งค่า **Settings → Pages → Deploy from a branch → main / (root)** เพื่อเผยแพร่เป็นเว็บไซต์
